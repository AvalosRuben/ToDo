# ToDo CRUD

Basic CRUD project using **go lang** for the backend and **React ts** for the frontend.

## Main Technologies

- Go lang
- Gin-gonic
- GORM
- Typescript
- React
- Tailwind CSS

## Functionalities

The program uses a PostgresSQL Dockerized DB, and connects to it via GORM, to store the tasks and change them, all the basic CRUD operations were included: Creating a task, updating the Done state, getting the tasks and deleting a task.
